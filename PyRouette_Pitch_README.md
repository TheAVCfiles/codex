# Py.rouette Pitch Assets

Clean, print-ready source files for the Py.rouette COO/fund pitch:

- `PyRouette_Pitch_OnePager.html` — single-page executive memo.
- `PyRouette_Pitch_2Slide.html` — two-slide briefing deck.

## Export to PDF

1. Open either HTML file in a browser.
2. Print (`Ctrl/Cmd + P`).
3. Save as PDF.
4. Disable browser headers/footers for a clean final export.

Both files are designed to print in standard US Letter dimensions.
