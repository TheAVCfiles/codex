# Ballet Bank — Studio Credits to Stagecoin (One Pager)

## What this is

Artists earn internal studio credits from choreography activity. Those credits can be converted to Stagecoin when the artist chooses portability.

## Why studios like this model

- Day-to-day flow stays familiar and studio-controlled.
- Artists are not forced to use wallets immediately.
- Conversion can be gasless for artists through a relayer.

## Pilot recipe

1. Seed a small treasury.
2. Run a small creator cohort.
3. Batch conversion windows to reduce gas.
4. Keep compliance internal until external cashout is needed.

## Risk controls

- Admin roles in multisig.
- Rate limiting and conversion caps.
- Signed user consent for each conversion.
- Audited contract and relayer code before scale.
