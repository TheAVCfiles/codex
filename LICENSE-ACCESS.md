## License access

For commercial reuse, institutional deployment, training use, cohort use, derivative products, or private room access, request license access before using project materials beyond public viewing.

## Standard inquiry format

When requesting access, include:

1. Project or repository name
2. Asset or room requested
3. Intended use
4. Audience or organization
5. Duration of use
6. Whether the use is public, private, commercial, educational, or internal
7. Requested payment pathway: one-time, subscription, cohort license, enterprise retainer, or audit service

## Boundary rule

Public visibility is not commercial permission. Provenance proves origin. Licensing controls use.
