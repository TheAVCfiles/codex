# How DevOpps Works

DevOpps follows a simple, repeatable operational loop:

1. **Ingest opportunities** across education, grants, credits, fellowships, and platform access.
2. **Normalize into the spine** (`spine/opportunities.csv`) with consistent fields.
3. **Score opportunities** by immediate income impact, long-term positioning, leverage multiplier, and time cost.
4. **Generate artifacts** as Markdown and PDF for publication.
5. **Deploy to static docs** and maintain timestamped provenance via commit history.

This model keeps opportunity work strategic, not random.
