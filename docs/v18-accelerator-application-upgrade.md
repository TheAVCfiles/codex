# V18 Accelerator Application Upgrade

## Messaging Shift

Replace future-tense build language with deployment language.

### Old

- “We are building...”

### New

- “We are deploying...”

## Stronger Execution Line

Use this sentence in YC / Techstars applications:

> We’ve completed paid installs and are productizing the system into software.

## Narrative Advantage

This repositioning shifts evaluator perception from:

- idea stage → execution stage
- concept risk → commercialization proof

## Required Evidence to Support Claim

Include at least one artifact from each category:

1. Paid install confirmation
2. Before/after workflow output
3. Pilot timeline (7-day execution window)
4. Revenue or contract screenshot (redacted as needed)

## Application Checklist

- [ ] Replace “building” phrasing with “deploying” phrasing
- [ ] Add one concrete paid install data point
- [ ] Include sentence on productization path
- [ ] Show clear short-term expansion plan
