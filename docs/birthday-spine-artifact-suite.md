# Birthday Spine Artifact Suite v1.0

A reusable, portable annual identity snapshot designed to be copied into journals, AI systems, archives, and operating docs.

## Purpose

Use this once per year (at birthday rollover) to record:

- identity baseline,
- current system tension,
- trajectory,
- deprecated patterns,
- annual wish.

This is not a greeting card. It is a checksum.

## Yearly Versioning Protocol

- Create one file per year, e.g. `birthday-spine-2026.md`.
- Keep all four variants aligned to one core truth.
- Archive unchanged prior years; never retro-edit the emotional record.
- If systems evolve, increment schema (`v1.1`, `v2.0`) but preserve prior versions.
