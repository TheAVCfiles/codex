StagePort is a **choreographic command-and-proof layer**: retained execution memory that preserves command intent, execution context, corrections, and proof over time.

> A command has no value unless there is a surface capable of executing it.

The “right-hand” role is modeled as an execution primitive:

- receives nonlinear commands,
- preserves style under pressure,
- executes and improves in feedback loops,
- retains score continuity across time,
- stabilizes execution without repeated restatement.

StagePort’s claim is to preserve this **function** as infrastructure (not replace people).
