# Founder Command Board (Apply / Build / Deploy / Monetize)

## Objective

Translate a large platform vision into small, contractable services that produce immediate revenue while preserving long-term IP optionality.

---

## 1) Apply (Fast Income Pipeline)

### AI Work Marketplaces

- Mercor — target AI evaluator, rubric designer, prompt tester roles.
- Invisible Technologies — target AI trainer/evaluator and ops analyst roles.
- Braintrust — position as AI evaluation + prompt architecture specialist.
- Scale AI / Labelbox / Alignerr / DataAnnotation.tech — maintain as stepping-stone channels.

### Job Boards

- remotech.ai
- Wellfound
- ZipRecruiter

### Weekly Application Target

- 10 total submissions/week:
  - 4 marketplace roles
  - 4 job board roles
  - 2 direct founder outreach messages

---

## 2) Build (Productized Consulting Offers)

Package services into fixed-scope offers clients can understand quickly.

### Offer A — AI Evaluation System Design

**Price:** $3k–$10k  
**Deliverables:**

- scoring rubric
- evaluator prompt set
- annotation instructions
- sample evaluation dataset
- quality benchmark report

### Offer B — Hallucination-Safe Knowledge Extraction

**Price:** $8k–$30k  
**Deliverables:**

- extraction pipeline
- validation and audit framework
- provenance/traceability map
- structured dataset handoff

### Offer C — Prompt Architecture Install Sprint

**Price:** $6k–$7.5k (2 weeks)  
**Deliverables:**

- role/system prompt architecture
- fallback and guardrail logic
- test harness + acceptance criteria
- handoff runbook

---

## 3) Deploy (Portfolio + Trust Layer)

### Public Hub (Single Front Door)

Recommended structure:

- `/Decrypt`
- `/StagePort`
- `/Prompt-Systems`
- `/Research`
- `/Consulting`

Each page should include:

- one architecture diagram
- one plain-language explanation
- one proof artifact (demo screenshot, receipt, or case snippet)

### Core Message

Do not sell the full platform first. Sell one useful subsystem with clear outcomes.

## 4) Monetize (90-Day Revenue Mix)

### Revenue Channels

1. Install sprints
2. Domain pack licenses
3. Template sales
4. Subscription layer

### Suggested 90-Day Target

- 3 installs @ $7.5k = $22.5k
- 2 licenses @ $2.5k = $5k
- 50 templates @ $99 = $4.95k

**Total modeled revenue:** **$32.45k**

---

## 5) Domain Pack Strategy (Keep Core Private)

### Layer 1: Core Kernel (not sold)

- scoring logic
- orchestration patterns
- ontology and governance methods

### Layer 2: Domain Packs (sold)

- AI Evaluation Pack
- Knowledge Extraction Pack
- StagePort Studio Pack

### Layer 3: Public Surface

- marketing pages
- docs
- case snapshots

This preserves optionality for consulting, licensing, or eventual company sale.

---

## 7) Positioning Language

Use:

- **AI Evaluation Systems Architect**
- **AI Knowledge Systems Architect**

Avoid vague labels like:

- “I do AI work.”

---

## 8) Rule of Execution

Sell tools first, not the total vision.

**Formula:**

1. Package one subsystem.
2. Land one paid implementation.
3. Convert implementation into repeatable offer.
4. Accumulate proof artifacts and references.
5. Expand toward platform over time.
