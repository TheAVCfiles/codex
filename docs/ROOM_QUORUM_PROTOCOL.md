# Room Quorum Protocol

Date: 2026-05-08

## Purpose

This protocol defines the minimum conditions required before any client room in The House may activate.

A room does not activate because a client is excited, anxious, persuasive, urgent, flattering, panicked, or confused.

A room activates when quorum is satisfied.

## Core Law

> No JETÉ without quorum.

## Minimum Quorum Elements

A client room may move to JETÉ only when all required elements are current:

1. Payment state
2. Agreement state
3. Scope state
4. License state
5. Access state
6. Evidence state
7. Operator review

If any element is unclear, overdue, incomplete, disputed, or unsafe, the room remains in FERMATA.

## Quorum Checklist

| Quorum Element | Required Condition | Failure State |
| --- | --- | --- |
| Payment | Deposit/current invoice paid or approved written exception | FERMATA — Payment Review |
| Agreement | Signed agreement or explicit written acceptance | FERMATA — Agreement Review |
| Scope | Deliverables, exclusions, and phase boundary defined | FERMATA — Scope Review |
| License | Internal use, demo use, commercial use, or enterprise use clearly stated | FERMATA — License Review |
| Access | Portal/repo/file/system access bounded by role and phase | FERMATA — Access Review |
| Evidence | Prior work, induced performance, receipts, and decisions preserved | FERMATA — Evidence Review |
| Operator | Human review complete; no unresolved hydrant or drift flags | FERMATA — Operator Review |

## Activation States

### GLISSADE

Room is forming.

Allowed:

- intake
- diagnostic review
- proposal drafting
- payment request
- agreement prep
- limited non-sensitive discussion

Not allowed:

- deep implementation
- handoff of protected architecture
- unbounded access
- production work
- commercial deployment rights

### FERMATA

Room is held.

Allowed:

- clarification
- payment follow-up
- change order drafting
- evidence preservation
- license review
- scope reset

Not allowed:

- new unpaid work
- expanded access
- deployment
- unlicensed reuse
- emotional renegotiation

### JETÉ

Room is active.

Allowed:

- scoped work
- agreed deliverables
- implementation inside the paid phase
- approved access
- receipt generation

### CODA

Room is closing.

Allowed:

- closeout
- access revocation
- license reminder
- receipt/export
- final invoice/payment reconciliation

### RESET

Room is archived or prepared for next gate.

Allowed:

- next-phase offer
- new agreement
- new payment gate
- new room opening

## Payment Quorum

Payment is current when:

- the required invoice is paid, or
- the agreed deposit is paid, or
- an approved written exception exists.

Partial remittance does not automatically activate full scope.

A deposit may activate only the deposit-defined window.

## Agreement Quorum

Agreement is current when:

- the signed agreement exists, or
- written acceptance of exact terms exists, and
- no material open dispute remains.

Post-signature changes require a change order.

## Scope Quorum

Scope is current when:

- deliverables are listed
- exclusions are listed
- phase boundary is stated
- acceptance criteria are stated
- correction window is stated
- next phase is separate

If the client requests work outside the current scope, the room returns to FERMATA until a change order is accepted.

## License Quorum

License is current when the client knows:

- what they may use
- where they may use it
- whether use is internal, demo, commercial, or enterprise
- whether sublicensing is prohibited
- whether AI ingestion is prohibited
- whether screenshots, cloning, or derivative builds are prohibited

Observation is not ownership.

Review access is not a license.

## Access Quorum

Access is current when:

- access is role-limited
- access is phase-limited
- access is time-limited where applicable
- sensitive files are excluded unless required
- private keys and credentials are never exposed
- export/screenshot rules are stated

## Evidence Quorum

Evidence is current when:

- payment records are linked
- agreement records are preserved
- deliverable records exist
- induced performance is documented
- major decisions are logged
- closeout path is available

## Operator Review

Operator review confirms:

- no unresolved hydrant violation
- no unresolved extraction drift
- no unresolved payment dispute
- no unresolved scope dispute
- no unresolved platform/partner policy conflict
- no unsafe access expansion

## Client-Safe Quorum Copy

> The room is not yet active because quorum is incomplete. The next step is to complete the payment, agreement, scope, license, or access requirement listed below.

> Once quorum is satisfied, the room can move to JETÉ and work may proceed inside the paid scope.

## Operator Rule

Do not explain with emotion.

Point to the missing quorum element.

## Final Compression

A room is safe when the rules are legible before the correction is needed.
