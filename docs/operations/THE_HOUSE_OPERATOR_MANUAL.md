# THE HOUSE OPERATOR MANUAL

## Operational States

### Inquiry State

Capture lead context, constraints, and objective. No implementation starts in inquiry.

### Deposit State

Collect payment commitment and scope baseline. Validate fit before activation.

### Active State

Run approved workstream with defined cadence, evidence capture, and checkpoints.

### Gated State

Pause privileged access until prerequisite payment, documentation, or approvals are complete.

### Paused State

Suspend execution without dissolving records; preserve ledger continuity.

### Closeout State

Deliver outputs, receipts, and exported evidence packet; define residual obligations.

### License State

Apply licensing terms for frameworks and artifacts; confirm rights, limits, and attribution.

## Core Workflows

- Stripe workflows: create payment links, verify settlement, map payments to room IDs.
- Payment gating: unlock implementation only after payment state changes to confirmed.
- Room activation: bind team, timeline, scope, and decision authority.
- Receipts: issue durable receipts tied to service milestone and room state.
- Evidence exports: package decisions, deliverables, and timeline events.
- PDF closeouts: generate final closeout summary with signatures/approvals where needed.
- Startup-credit intake: track credit pathways, eligibility, and activation sequence.
- Sprint activation: initiate 7-day intensive with daily checkpoint protocol.
- Client drift detection: monitor scope and decision drift; trigger re-baseline.
- Escalation procedures: route disputes, blockers, and governance exceptions.
