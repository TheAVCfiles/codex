# Grant Engine Playbook (2026)

This guide turns a complex creative-technology practice into a repeatable grant workflow.

## Core Principle

Treat grant submissions like reusable deployments:

- Keep one **master dossier**.
- Export program-specific packets.
- Submit quickly with minimal rewrites.

## Funding Habitats

### 1) Artist / Creative Grants

Best entry point for independent creators.

- Creative Capital
- NYFA fellowships
- NYC DCLA programs
- Foundation for Contemporary Arts

### 2) Creative Technology / Digital Storytelling

Strong fit for interactive narrative systems.

- Mozilla Creative Media Awards
- Knight Foundation media innovation programs
- Onassis ONX Studio

### 3) Research / Incubator Fellowships

Adds institutional credibility and network effects.

- NEW INC
- Eyebeam Fellowship/Residency
- MIT Open Documentary Lab programs

### 4) Interactive Narrative / Game Funding

Useful for narrative engines and experimental story platforms.

- Interactive fiction grants
- Narrative game funds
- Experimental storytelling labs

## The Master Folder

Create a canonical project directory:

```text
AVC_GRANT_ENGINE/
├─ core_assets/
│  ├─ master_project_overview.pdf
│  ├─ bio_allison_van_cura.pdf
│  ├─ systems_architecture_diagram.png
│  └─ project_timeline.pdf
├─ dtg_module/
├─ mythos_module/
├─ betta_module/
└─ export_packets/
```

## Four Universal Documents

1. **Project overview** (2 pages)
2. **Creator bio**
3. **Architecture diagram**
4. **Timeline**

These files should remain stable and versioned.

## Submission Packet Pattern

Each opportunity gets a focused ZIP. Example:

```text
DecryptTheGirl_GrantPacket.zip
├─ overview.pdf
├─ bio.pdf
├─ architecture_map.png
├─ screenshots/
└─ interactive_demo.html
```

## Fast Submission Workflow

1. Copy relevant module files into `export_packets/`.
2. Add grant-specific statement/budget if needed.
3. Compress into ZIP.
4. Submit through the portal.

Target runtime: **10–15 minutes per application** once assets are prepared.

## Compliance Rule (Non-Negotiable)

You can hold multiple grants at once, but do **not** charge two funders for the same expense.

Use a simple funding matrix:

| Grant   | Scope it funds       |
| ------- | -------------------- |
| Grant A | Platform development |
| Grant B | Research track       |
| Grant C | Public exhibition    |

## Recommended Weekly Pipeline

- Track opportunities in:
  - Submittable Discover
  - NYFA Opportunities
  - Creative Capital updates
- Apply to multiple smaller opportunities first for social proof.
- Reuse core materials; only customize framing and budget lines.

## Positioning Language

Use a studio framing for stronger institutional readability:

> **AVC Systems Studio**  
> Independent Narrative Technology Research

This keeps individual authorship while communicating operational seriousness.

## Messaging Template (Short)

**Project:** _DeCrypt the Girl_  
An interactive literary operating system where poems become navigable rooms and readers unlock narrative pathways through symbolic ciphers.

**Phases:**

- Phase 1: Interactive scroll prototype
- Phase 2: Reader decoder system
- Phase 3: Public narrative platform

## 30-Day Execution Sprint

- **Week 1:** Finalize core overview + system map.
- **Week 2:** Record a 3-minute demo + prepare samples.
- **Week 3:** Submit 3 applications.
- **Week 4:** Queue 3–5 additional calls using the same packet engine.

## Why This Works

The bottleneck is usually not eligibility; it is translation and packaging speed.

A reusable grant engine converts a complex ecosystem into clear, fast, repeatable submissions.
