# Canonical Stack Brief: Recursive Semantic OS

This brief captures a coherent architecture split between brand, invention, and implementation layers.

## Recommended Hierarchy

1. **Global AVC Systems, Inc.** — Commercial/legal entity.
2. **AVC Systems Studio** — Umbrella operating studio and publishing/licensing shell.
3. **Recursive Semantic OS™** — Core invention (semantic computation + governance substrate).
4. **Semantic Spine™** — Technical execution layer (schemas, APIs, provenance, state logic, auditability).
5. **GlisseOS™** — Temporal choreography engine (adaptive timing, transition legality, elasticity).
6. **MythOS™** — Meaning-generation layer (symbolic compression, recursive interpretation, constitutional framing).
7. **Exclopedia™** — Enterprise utility layer (executable glossary, harmonized terms, reconciliation workflows).
8. **DeCrypt the Girl™** — Narrative/media universe.

## Two-Business Strategy

### Business A: Infrastructure / Enterprise (revenue-first)

- **Semantic Spine™**
  - Credentialing and provenance systems
  - API and governance infrastructure
- **Exclopedia™**

### Business B: Mythotechnical Media (gravity-first)

- MythOS
- GlisseOS
- DeCrypt the Girl
- Recursive symbolic narrative products

## Core Distinction to Preserve

- **Execution engines** generate actions.
- **Governance engines** decide whether actions are permitted.

This distinction is central to positioning GlisseOS and related state-machine work as control architecture rather than aesthetic metaphor.

## Positioning Principle

**Grace on the surface. Governance underneath.**

Public narrative should stay legible and compressed; deep architecture remains available through evidence, receipts, and auditable implementation.
