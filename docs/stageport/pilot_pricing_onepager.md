# StagePort Pilot Pricing One-Pager

## StagePort Pilot — Technical Element Scoring and Record Integrity

### What this is

A limited-scope pilot that converts training clips into structured technical records using the StagePort methodology.

This pilot helps studios evaluate:

- clarity of technical feedback
- usefulness of structured scorecards
- parent-facing progress documentation
- internal record consistency

### Pilot Scope (Fixed)

- **Participants:** up to 10 students (or 20 clips)
- **Elements:** 1 element family (for example, Turns or Leaps)
- **Outputs:**
  - Technical Element Summary (PDF)
  - Summary Scorecard (CSV)
- **Turnaround:** 14 days
- **Duration:** one-time pilot (no auto-renew)

### Pilot Fee

**$750** — one-time pilot fee

Includes:

- intake validation
- scoring and report generation
- output delivery
- pilot-scope method license

No subscription. No long-term commitment.

### What studios receive

- clear technical summaries
- consistent scoring language
- parent-safe documentation
- records suitable for internal use

### What studios do not receive

- access to the underlying scoring method
- rights to replicate or resell the method
- rights to train AI models on outputs
- ongoing processing beyond pilot scope

### Optional conversion

If the pilot is successful, studios may:

- extend into a term license, or
- expand pilot scope (students, element families, and reporting cadence)

Conversion terms are discussed after pilot completion.
