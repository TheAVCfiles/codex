# StagePort Enterprise Demo + Close Script

## Positioning (use verbatim)

**StagePort — Operator System for Structured Execution.**

Converts unstructured input into auditable output under controlled authority.

## Demo Spine (12-minute flow)

1. **Input ingest (2 min).**
   - Ask for one messy input: notes, transcript, draft process, or operating pain.
2. **Live conversion (5 min).**
   - Run Input → Structured Spec → Output artifact.
   - Keep narration minimal; show the system doing work.
3. **Governance reveal (3 min).**
   - Show authority state and audit trace for the output.
4. **Close bridge (2 min).**
   - Move directly to single-workflow pilot.

## Close sequence (operator language)

Use this sequence in order.

### 1) Reframe

> This replaces the alignment phase, not your team.

### 2) Reduce scope

> We usually start with a single use case: one workflow, one team, one output loop.

### 3) Preserve control

> You can run this internally, or we can operate it with you initially.

### 4) Silent close

Stop speaking. Let procurement and operations ask the next question.

## Objection handling (short form)

- **"We already have tools."**
  - "Most teams do. This replaces the alignment between them."
- **"We need to evaluate internally."**
  - "Expected. Start with one contained workflow."
- **"Can this integrate with X?"**
  - "Yes. We validate the workflow first, then connect systems."

A contained deployment of StagePort for one workflow, validated end-to-end.

Use the phrase **pilot deployment** (never "setup fee").
