## StagePort / PyRouette Reference Pipeline

The movement stack now follows a consistent five-stage machine that can be reused across capture, scoring, and credentialing flows:

1. **Signal**

   - Capture pose, timing, and pressure inputs (camera skeletons, floor sensors, IMU telemetry).

2. **Validation**

   - Verify structural quality, confidence thresholds, subject consent, and enclave isolation flags.

3. **Regime**

   - Route each phrase through finite-state choreography logic (`GLISSADE → JETÉ → FERMATA → CODA`).

4. **Action**

   - Execute scoring math (`TES + PCS - deductions + bonuses`) with element-level terms (`BV × DD + GOE`).

5. **Record**
   - Persist score outputs and choreography signatures as hash-addressed ledger entries for provenance.

This creates a minimal working loop for prototype demonstrations:

`video clip → pose detection → element classification (ex: tendu / jeté) → JSON phrase output → score artifact`

The same loop supports both human-facing judging transparency and machine-verifiable movement ownership.
