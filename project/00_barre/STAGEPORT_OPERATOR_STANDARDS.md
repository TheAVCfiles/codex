# StagePort Operator Standards

## Prime Rule

Preserve the bar. Do not show the bar unless the audience is being trained.

## Execution Standard

A system is not elite because it is overprogrammed. A system is elite when it can maintain clean standards under changing room conditions.

## Rehearsal Memory

Runoff is not waste. Runoff is phrase memory. It may contain future canonical material, but it is not public by default.

## Promotion Rule

No artifact becomes canonical until it passes:

1. Embodiment test
2. Audience-read test
3. Technical-cleanliness test
4. Context-integrity test
5. Operator-sovereignty test

## Reusable Runoff Doctrine

Runoff is not failed material. It is retained movement intelligence.
A phrase may fail in one runtime because of score, cast, level, tempo, emotional load, spatial geometry, or audience contract. That failure does not invalidate the phrase globally.
StagePort preserves transferable sequences beyond singular runtime execution so they can be recast, inverted, slowed, reversed, assigned to another dancer, moved to the left side, or promoted into future work.
Everything may be retained.
Not everything may perform.
Not everything that fails should be discarded.

## Audio as Runtime Key

Music is not ornament. Music is an executable cue layer.
When foundational phrases have been properly encoded through repetition, a specific sonic profile can activate stored movement memory without requiring full cognitive recomputation.
StagePort treats audio as a retrieval key for embodied local storage.

## Stage Rule

The public sees executable clarity, not internal scaffolding.

## Bar Rule

Foundational repetitions stay preserved even when invisible.
