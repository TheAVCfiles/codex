# Pilot Leverage Playbook

A practical operating guide for converting a fixed-scope pilot into repeatable startup infrastructure.

## Core Reframe

Treat each engagement as a **sealed pilot experiment**, not an open-ended rescue mission.

- Success criteria = scope-complete delivery and runnable proof artifact.
- Founder behavior is not part of technical acceptance criteria.
- Phase I completion does not obligate Phase II continuation.

## Separation Model

Evaluate two independent variables in parallel:

1. **System viability**: did the architecture and workflow validate?
2. **Partner viability**: is the founder relationship stable and actionable?

A valid system with a non-viable partner is still a successful technical pilot.

## Pilot Evidence Stack

For every 60-day pilot, package evidence as institutional-grade artifacts:

- Architecture packet
- Runnable demo artifact
- Governance documentation
- Sprint plan
- Backend blueprint

Translate these into a concise case-study claim:

> "Safety-signal architecture prototype validated in pilot environment."

## Neutral Disengagement Protocol

Use procedural language, not emotional language.

Template:

> "Phase I deliverables have been completed according to the signed scope. Phase II activation requires the Phase II agreement and payment. If the client chooses not to proceed at this time, the Phase I engagement will conclude as scheduled."

## 3-Week Signal Extraction Window

When a pilot is active, collect three proof types immediately:

1. **Before/after state**
   - No governance structure → documented governance model
   - No artifact trail → reproducible artifact trail
   - No escalation model → defined escalation protocol
2. **Operational outputs**
   - Decision receipts, diagrams, protocols, install evidence
3. **Founder quote**
   - One paragraph describing operational clarity gained

## One-Page Case Study Format

Use a compact PDF called:

**Governance Install: Pilot Deployment Case Study**

Sections:

1. Problem
2. Solution architecture
3. Deployment steps
4. Artifacts generated
5. Founder quote
6. Next phase options

   - Compliance memo template
2. **Startup Dossier Kit** (~$499)
   - Investor memo template
   - Governance architecture doc
   - Technical roadmap template
   - Demo artifact guide
3. **Architecture Sprint** ($3k–$7k)
   - Custom dossier build and deployment plan

## Dossier Compiler System

Implement a reusable template pipeline:

```text
/DOSSIER_TEMPLATE
  overview.md
  architecture.md
  compliance.md
  build_spec.md
  credit_packet.md
  demo_artifact.md
```

Each file should include placeholders:

- `PROJECT_NAME`
- `FOUNDER`
- `SYSTEM_TYPE`
- `DEPLOYMENT_TARGET`

Goal: duplicate, fill, export in 45–60 minutes.

- YC Startup School community
- Indie Hackers
- Hacker News (Show HN)
- Product Hunt
- Founder and AI builder Slack/Discord groups

Institutional channels:

- University safety / HCI / AI governance labs
- Women’s safety and impact accelerators
- Grant-funded startup ecosystems

## Positioning Rule

Lead with outcomes, not architecture jargon.

Avoid:

> "I built a governance system."

Prefer:

> "I help early-stage startups become compliance- and grant-ready in 30 days."

## 60-Day Execution Plan

1. Publish one flagship artifact (demo page + architecture map + short video)
2. Convert active pilot outputs into one-page case study
3. Open 2–3 new pilot slots with fixed scope + fixed fee
4. Reuse the dossier compiler for rapid delivery
5. Apply to institutional programs after pilot proof exists

## Strategic Principle

Infrastructure survives unstable environments.

Treat founder volatility as environmental noise; preserve and compound the architecture assets.
