# Runoff Repertoire Ledger

## Sidebar Phrases

Phrases with transferable value not assigned to the current production.

## Recast Candidates

Material likely to work with another dancer, direction, tempo, level, or score.

## Barre-Level Invariants

Fundamental sequences that must survive every public layer.

## Retired / Compost

Material not currently useful but contextually meaningful.

## Evaporated

Released material. No action.
