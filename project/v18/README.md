# V18 White-Label Private Operating Environment

This package is a **repeatable Phase I install system** designed to deliver premium client artifacts quickly without rebuilding from scratch.

## Goals

- Debranded and enterprise-safe language
- Local-first runtime (no API, no backend, no CDN)
- Fast customization through config only
- Consistent deliverables that preserve pricing power

## Folder Layout

```
project/v18/
├── README.md
├── system.json
├── config/
│   ├── brand.json
│   ├── tone.json
│   └── product.json
├── data/
│   └── client_memory.json
└── ui/
    └── index.html
```

## Operating Model

1. Duplicate this folder per client.
2. Update `system.json` + `config/*.json`.
3. Open `ui/index.html` locally.
4. Capture session outputs.
5. Export JSON snapshot and deliver ZIP.

## Delivery SOP (Steve Jobs-style discipline)

1. **Freeze structure:** Do not alter module layout per client.
2. **Mirror client language:** Adapt wording via `config/tone.json` only.
3. **Single source of truth:** All client identity changes live in config files.
4. **Show, don’t explain:** Deliver a guided artifact with clear path buttons.
5. **Control next step:** Every install ends with activation gate.
