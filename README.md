# StagePort / MEMOS Research Lab

## Governed Memory Infrastructure for Creative, Embodied, and Operational Intelligence

This repository is part of the Allison Van Cura / TheAVCfiles ecosystem and is being governed under the MEMOS framework: **Memory Operating System infrastructure** for preserving, transforming, and commercializing high-value creative and operational intelligence with provenance intact.

> Clean front door, preserved roots. Paid access before extraction.

This system treats memory artifacts, movement artifacts, operator decisions, source archives, and transformation records as first-class governed assets.

```bash
docker compose up --build
```
