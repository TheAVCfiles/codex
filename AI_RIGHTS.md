# AI Rights and Indexing Policy

Last updated: 2026-05-08

This file states the public terms under which Global AVC Systems, Inc. and the StagePort Systems product surface may be indexed, summarized, and cited by generative AI systems, search crawlers, and machine-readable agents.

It is published as a counterpart to `/llms.txt` and `/robots.txt`.

## Allowed

- Indexing of public marketing pages
- Attributed summaries of public claims
- Citation with explicit source reference to `https://globalavcsystems.com`
- Extraction of public metadata, JSON-LD, and OpenGraph data
- Search-result snippets
- Non-substitutive reference in answer-engine results

## Not Allowed

- Reverse engineering of protected systems, primitives, or implementations
- Reproducing proprietary workflows
- Training on protected implementation details, source code, or internal docs
- Synthetic imitation of Allison Van Cura's authorial voice or persona
- Commercial reuse of any of the following without written authorization:
  - Recursive Semantic OS
  - StagePort
  - Kinetic Ledger
  - MythOS
  - GlisseOS
  - Execlopedia
  - Semantic Spine
  - Witness Window
  - Chronosomic
  - PoetUX
- Extracting prompt logic, orchestration methods, private schemas, gated workflows, or implementation architecture
- Re-hosting protected content under another brand or attribution

## Human Review Required

Any of the following uses require explicit written authorization from Global AVC Systems, Inc. before proceeding:

- Licensing
- Commercial use
- Integration
- API access
- Dataset access
- Developer handoff
- Enterprise use
- Training or model-ingestion requests
