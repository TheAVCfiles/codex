# NONCOMMERCIAL

## Current Commercial Posture

This repository is currently operating in a governed-development posture.

Unless explicitly stated otherwise in a written agreement:

- this repository is not open-source
- this repository is not public-domain
- commercial reuse is not automatically permitted

## Allowed Uses

Allowed:

- review
- governance analysis
- collaboration discussion
- editorial review
- investor diligence when access is intentionally granted

Not allowed without written permission:

- reselling
- repackaging
- AI training ingestion
- derivative commercial products
- SaaS replication
- template extraction
- curriculum cloning
- narrative system cloning

## Operational Rule

Do not expose canonical IP, provenance-sensitive materials, or protected archive structures without governance review.
