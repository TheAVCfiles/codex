# Berkshire AI Help Desk — 14-Day Prototype

## Thesis

The Berkshires does not need more AI hype. It needs a trusted local knowledge layer where residents, businesses, libraries, artists, and educators can ask practical questions and receive sourced, human-stewarded answers.

## Pilot

A 5-agent local AI prototype trained only on approved Berkshire resources.

## Agents

1. BIC Innovation Guide
2. Berkshire Library Steward
3. Café / Salon Concierge
4. Arts Organization Mentor
5. Workforce Training Navigator

## What users can ask

- Where can I learn practical AI locally?
- What grants exist for artists or small businesses?
- How can a salon, café, or studio use AI safely?
- What programs help students, seniors, or workers?
- How do I preserve local archives or family records?

## Trust model

Every answer includes:

- source document
- organization
- human steward
- last reviewed date
- confidence level
- correction/escalation path

## Differentiator

This is not surveillance and not a generic chatbot. It is bounded, human-stewarded civic retrieval.

## Ask

- 5–10 source documents
- 3 partner contacts
- permission to run one demo session
- one local steward per agent

## 14-day output

- working demo
- source ledger
- 5 agent cards
- public prompt interface
- basic answer logs
- pilot report PDF

## Positioning line

Berkshire AI Help Desk makes local knowledge searchable, trustworthy, and human-readable.
